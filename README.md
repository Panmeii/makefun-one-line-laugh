One funny line for **The One-Line Laugh** on make.fun: a single sentence of 122 characters about buying a planner to get your life together, only to end up with your failures beautifully organised by date. The Node program (`main.ts`) writes the line to `entry.txt` in the output directory, then verifies it against the competition gate — UTF-8 text of 1 to 200 characters, not only whitespace, exactly one sentence on one line — and exits non-zero if any check fails.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
